# 투자알람

크레마지수(매수)와 주간 RSI 매도알람을 매일 아침 자동 계산해 **비밀번호로 잠긴 대시보드 웹페이지**로 보여 줍니다.
페이지를 열면 최근 30일 안의 매수·매도 신호와 현재 상태가 팝업으로 먼저 뜹니다.

| 파일 | 역할 |
| --- | --- |
| `build_site.py` | 데이터 수집 → 신호 계산 → 결과를 비밀번호로 암호화 → `site/index.html` 생성 |
| `site_template.html` | 대시보드 화면 (로그인·팝업·게이지·차트·신호 기록) |
| `.github/workflows/site.yml` | 매일 07:30(한국시간) 자동 실행 → GitHub Pages에 배포 |
| `settings.json` | 규칙(비중, 기준점수, 72/50, 18개월)과 팝업 기간 |
| `core/` | 데이터 수집과 신호 계산 |
| `app.py` | (예전 Streamlit 버전, 참고용) |

## 사용
- 대시보드 주소 접속 → 비밀번호 → 알림 팝업 확인. '이 기기에서 비밀번호 기억'을 체크하면 다음부터 바로 열립니다.
- 바로 다시 계산하려면: 저장소 **Actions → 대시보드 갱신 → Run workflow**
- 규칙 바꾸기: `settings.json` 수정 → 저장하면 자동으로 다시 계산·배포
- 비밀번호 바꾸기: Settings → Secrets and variables → Actions → `SITE_PASSWORD` 수정 → Run workflow

결과 데이터는 페이지 안에 AES-GCM으로 암호화되어 있어 비밀번호 없이는 볼 수 없습니다.
테스프레소 영상 규칙을 자동 계산하는 도구이며 투자 권유가 아닙니다. 판단과 책임은 본인에게 있습니다.
